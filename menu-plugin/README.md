# KRONOS Menu Plugin v0.2.0 (`menu-plugin`)

Модернизированный модульный плагин компас-меню для **Pumpkin 26.3** (`wasm32-wasip2`, WASI Preview 2) с интеграцией всех 5 новых плагинов сервера KRONOS: `kronos-essentials`, `kronos-warps`, `kronos-economy`, `kronos-chat` и `kronos-ranks`.

## Сохранённая базовая логика
- Безопасная выдача компаса новичкам и при респавне (без перезаписи предметов), открытие меню по ПКМ (главная и вторая рука, защита от дребезга 150 мс и проверка `is_movement_locked()`).
- 54-слотовое сундучное GUI для Java Edition (`Screen::Generic9x6`, `Gui::new`).
- Нативные формы `SimpleForm` и `CustomForm` для Bedrock Edition.
- Персональные настройки (погода, время, живой HUD-компас, звук упоминаний, режим уединения, авто-выдача компаса) с атомарным сохранением в `settings.json` (`.json.tmp` -> `fs::rename`).

## Обновлённое главное меню (слоты 20–34)
- **Слот 20 — Телепортация и дома:** переход в навигатор (`/spawn`, `/rtp`, `/warps`, `/homes`, `/sharehome`).
- **Слот 22 — Экономика и рынок (`kronos-economy`):** отображение живого баланса из `economy.json`, памятка `/pay`, `/baltop`, `/trade` (`$`).
- **Слот 24 — Чаты и общение (`kronos-chat`):** памятка по Локальному (100 блоков), Глобальному (`!`), Торговому (`$`), ЛС (`/msg`, `/r`), `/ignore` и облачкам над головой.
- **Слот 29 — Ранги и привилегии (`kronos-ranks`):** актуальная витрина всех **12 русских рангов** (`[Игрок]`, `[VIP]`, `[Премиум]`, `[Креатив]`, `[Герой]`, `[Титан]`, `[Дракон]`, `[СПОНСОР]` + 4 стафф-ранга) с указанием всех команд (`/fly`, `/feed`, `/heal`, `/hat`, `/workbench`, `/enderchest`, `&a/&b`).
- **Слот 31 — Настройки игрока:** личная погода, время, HUD-компас, упоминания, уединение, авто-компас.
- **Слот 33 — Правила и безопасность:** правила сервера и быстрый переход к `/auth`, `/changepass`, `/logout`.

## Сборка и тестирование

Добавьте `"examples/menu-plugin"` в `members` корневого `Cargo.toml` и выполните:

```bash
cargo test -p menu-plugin
cargo build --release -p menu-plugin --target wasm32-wasip2
```

Готовый модуль `target/wasm32-wasip2/release/menu_plugin.wasm` скопируйте в папку `plugins/` сервера Pumpkin.
