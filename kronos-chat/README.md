# KRONOS Chat v1.0.0 (`kronos-chat`)

Модульная система чата для Minecraft-сервера на ядре **Pumpkin 26.3** (`wasm32-wasip2`, WASI Preview 2): каналы (локальный, глобальный, торговый), личные сообщения, анти-спам, защита от инъекций и облачка текста над головой.

## Каналы чата

| Канал | Триггер | Радиус / Охват | Кулдаун | Формат |
| :--- | :--- | :--- | :-: | :--- |
| **Локальный** | По умолчанию | 100 блоков (в том же мире) | — | `§8[§fЛ§8] {Префикс}{Ник} §8» §f{Текст}` |
| **Глобальный** | Первый символ `!` | Весь сервер | 3 сек | `§8[§6Г§8] {Префикс}{Ник} §8» §f{Текст}` |
| **Торговый** | Символ `$` или `/trade` / `/ad` | Весь сервер + звук монетки | 30 сек | `§8[§e§lТОРГ§8] {Префикс}{Ник} §8» §e{Текст}` |
| **Личные сообщения** | `/msg`, `/tell`, `/w`, `/r` | Отправитель и получатель + колокольчик | — | `§8[§dЯ §8-> §d{Ник}§8] §f{Текст}` |

- Если рядом в локальном чате 0 получателей — отправителю выводится подсказка `§7(Вас никто не услышал)`.
- При отправке сообщения в локальный чат над головой игрока на **4.5 секунды** появляется облачко `§e«§f{Текст}§e»` (до 40 символов с `...`), автоматически исчезающее по `ServerTickEndEvent`.

## Безопасность и фильтры

- **Защита от инъекций:** полная очистка управляющих символов и сырых символов `§`.
- **Цветной чат (`&`):** работает только при наличии права `kronos-ranks:chat.color` (или `kronos-ranks:chat.color.all`).
- **Анти-капс:** сообщения длиннее 5 символов, где >60% букв заглавные, автоматически переводятся в нижний регистр.
- **Анти-флуд:** запрет повторной отправки одинакового сообщения подряд.
- **Анти-реклама:** блокировка IPv4-адресов и доменов (`.ru`, `.com`, `.net`, `.gg`, `t.me`, `discord.gg`).

## Команды и права

| Команда | Право | Описание |
| :--- | :--- | :--- |
| `/msg <ник> <текст>` (`/tell`, `/w`) | `kronos-chat:use` (`Allow`) | Отправить личное сообщение |
| `/r <текст>` (`/reply`) | `kronos-chat:use` (`Allow`) | Быстрый ответ последнему собеседнику |
| `/trade <текст>` (`/ad`) | `kronos-chat:use` (`Allow`) | Отправить объявление в торговый чат (КД 30с) |
| `/ignore <ник>` | `kronos-chat:use` (`Allow`) | Добавить/убрать игрока в чёрный список |
| `/socialspy` | `kronos-chat:socialspy` (`Op(2)`) | Включить/выключить слежку за ЛС для стаффа |

**Дополнительные права:**
- `kronos-chat:bypass-cooldown` — обход кулдаунов глобального и торгового чата.
- `kronos-chat:bypass-filter` — обход анти-флуда, анти-капса и фильтра рекламы.
- `kronos-ranks:chat.color` — поддержка `&`-цветов в чате.

## Сборка и тестирование

Добавьте `"examples/kronos-chat"` в `members` корневого `Cargo.toml` и выполните:

```bash
cargo test -p kronos-chat
cargo build --release -p kronos-chat --target wasm32-wasip2
```

Скопируйте `target/wasm32-wasip2/release/kronos_chat.wasm` в папку `plugins/` сервера Pumpkin.
